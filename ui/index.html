关于

智桥 — 轻量的 MCP 桥接工具。

它做什么

在本机跑一个 MCP 服务，通过 Cloudflare 临时隧道暴露到公网， 让网页上的 AI 能读写你指定的文件夹、执行命令。 不依赖任何第三方账号，也没有会员限制。

安全须知

  • 公网地址没有额外保护，地址 + 令牌泄露就等于开门。
  • 不用的时候请关闭隧道，或直接退出程序。
  • 「允许运行命令」风险最高，不确定就先关掉。
  • 权限范围是硬边界，路径穿越和符号链接都会被拦。
