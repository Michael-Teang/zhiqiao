智桥-zhiqiao Mac 版 1.1.0
=======================

两个包，按朋友 Mac 的芯片选一个。


一、怎么判断选哪个
------------------

点屏幕左上角苹果菜单 → 「关于本机」→ 看「芯片」这一行：

  显示 Apple M1 / M2 / M3 / M4  →  用 mac-arm64 那个包
  显示 Intel Core i5 / i7 / i9  →  用 mac-x64 那个包

也可以在「终端」里执行 uname -m：
  输出 arm64   → 用 mac-arm64
  输出 x86_64  → 用 mac-x64

2020 年底之后出的 Mac 基本都是 Apple 芯片，用 arm64 那个。


二、安装步骤
------------

1. 解压 zip（用系统自带的「归档实用工具」，不要用第三方解压软件）
2. 把「智桥-zhiqiao.app」拖进「应用程序」文件夹
3. 按住 Control 键点图标，选「打开」，弹窗里再点「打开」

只做这一次，以后双击就能开。

如果方式 3 不行，打开「终端」执行：
    xattr -cr /Applications/智桥-zhiqiao.app

还不行就走：系统设置 → 隐私与安全性 → 拉到底部 → 「仍要打开」


三、为什么会提示无法验证
------------------------

这两个包没有做苹果开发者签名（需要 Apple 开发者账号，年费 99 美元，
还要在 Mac 上操作）。所以首次打开会被 Gatekeeper 拦住，按上面步骤
放行一次即可，之后正常使用。

这不是病毒。程序源码全部可查，网络行为只有两项：
  - 连 Cloudflare 建立隧道（cloudflared）
  - 监听本机 127.0.0.1 的 8765 端口


四、用过之后
------------

1. 打开程序
2. 点「开启隧道」，等 5-15 秒
3. 点「复制完整配置」
4. 粘到 ChatGPT / Claude 的连接器里

详细说明见压缩包里的「使用说明.txt」。


五、两个包的差别
----------------

完全相同，只有两处不同：
  - Electron 运行时（arm64 / x86_64）
  - 内置的 cloudflared 二进制（arm64 / x86_64）

功能、界面、配置目录、令牌全部一致。
