智桥-zhiqiao Mac 版 1.3.0
=======================

两个包，按 Mac 的芯片选一个。


一、怎么判断选哪个
------------------

点屏幕左上角苹果菜单 → 「关于本机」→ 看「芯片」这一行：

  显示 Apple M1 / M2 / M3 / M4  →  用 mac-arm64 那个包
  显示 Intel Core i5 / i7 / i9  →  用 mac-x64 那个包

也可以在「终端」里执行 uname -m：
  输出 arm64   → 用 mac-arm64
  输出 x86_64  → 用 mac-x64


二、安装步骤
------------

1. 解压 zip（用系统自带的「归档实用工具」）
2. 把「智桥-zhiqiao.app」拖进「应用程序」文件夹
3. 按住 Control 键点图标，选「打开」，弹窗里再点「打开」

只做这一次，以后双击就能开。

如果方式 3 不行，打开「终端」执行：
    xattr -cr /Applications/智桥-zhiqiao.app

还不行就走：系统设置 → 隐私与安全性 → 拉到底部 → 「仍要打开」


三、固定地址
------------

1. 打开程序，首次启动会自动连接固定地址（约 5-15 秒）
2. 如果固定地址还在连接，界面会先显示「临时加速地址」，可以先复制使用
3. 出现固定地址后，点「复制完整配置」
4. 粘到 ChatGPT / Claude 的连接器里

固定地址会一直保留：重启电脑、重启程序、断线重连都不会变。
只有点「概览 → 公网地址 → 更换地址」并确认，地址才会换。

如果概览页出现「注册固定地址」按钮，点一下按网页提示绑定免费账号。
绑定不会改变当前地址，只是保证这个固定地址长期可用。


四、连接审批
------------

新设备第一次请求连接时，程序会停下来等你在「连接记录」里批准：

1. 看设备名称、IP 地址和客户端信息
2. 点「允许」或「拒绝」
3. 3 分钟内不处理，请求会自动过期，对方需要重新申请连接

已允许的设备会显示在「设备记录」里。
同一客户端批准后，后续工具调用不会重复询问；只有更换公网地址或密钥导致记录刷新后，才需要重新批准。
每行的下拉框可以选「断开连接」；断开后需要你重新允许。


五、记忆库
----------

AI 完成任务前可以调用 `memory_save` 把摘要、路径、决定和下一步保存到本机。
下一个 AI 通过 `memory_search` / `memory_get` 读取同一条记忆。

程序默认开启「自动记录会话记忆」：每轮工具调用结束后空闲 60 秒，
会自动把这一轮的工具调用、参数摘要和结果写入记忆库，作为 AI 忘记调用
`memory_save` 时的兜底。自动记录不包含 AI 的完整聊天原文。

界面左侧「记忆库」可以查看、搜索、展开和删除这些记录。
记忆文件位置：~/Library/Application Support/zhiqiao/config/memory.json


六、工具包
----------

文件增强：hash_file、find_files
系统运维：list_processes、kill_process、network_info、disk_usage
桌面辅助：clipboard_get、clipboard_set、screenshot
记忆：memory_save、memory_search、memory_get、memory_list、memory_delete、memory_stats


七、为什么会提示无法验证
------------------------

这两个包没有做苹果开发者签名（需要 Apple 开发者账号，年费 99 美元，
还要在 Mac 上操作）。所以首次打开会被 Gatekeeper 拦住，按上面步骤
放行一次即可，之后正常使用。

程序源码全部可查，网络行为只有下面这些：
  - 固定地址模式：SSH 连接 proxy.tunnl.gg
  - 临时地址模式：cloudflared 连接 Cloudflare
  - 监听本机 127.0.0.1 的 8765 端口


八、两个包的差别
----------------

完全相同，只有两处不同：
  - Electron 运行时（arm64 / x86_64）
  - 内置的 cloudflared 二进制（arm64 / x86_64）

功能、界面、配置目录、令牌全部一致。
