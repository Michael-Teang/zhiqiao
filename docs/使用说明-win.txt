智桥-zhiqiao 1.1.0
=======

让网页上的 AI（ChatGPT / Claude）通过 MCP 操作这台电脑。


一、怎么用
----------

1. 双击「智桥-zhiqiao.exe」
2. 在「概览」页点「开启隧道」，等 5-15 秒
3. 出现公网地址后，点「复制完整配置」
4. 到 AI 里添加 MCP 服务器


二、两种连接方式
----------------

方式 A：客户端要求 OAuth（ChatGPT 就是这样）
------------------------------------------------
1. URL 填：https://xxxx.trycloudflare.com/mcp
2. 身份验证选：OAuth
3. 浏览器会自动打开授权页
4. 把「连接 AI」页的访问令牌粘贴进去，点授权
5. 完成

不需要手动填 Header，也不需要 client id / secret。

方式 B：客户端支持自定义 Header（Claude 等）
--------------------------------------------
点「复制完整配置」，把 JSON 贴进去。内容是：

{
  "mcpServers": {
    "my-computer": {
      "type": "http",
      "url": "https://xxxx.trycloudflare.com/mcp",
      "headers": { "Authorization": "Bearer 你的令牌" }
    }
  }
}

两种方式可以同时用，互不影响。


三、界面说明
------------

概览      服务状态、公网地址、请求统计
连接 AI   连接配置和访问令牌（OAuth 授权时要粘贴的那个）
权限范围  允许 AI 访问哪些文件夹、能否执行命令
可用工具  10 个工具的能力清单
关于      安全须知和配置文件位置


四、安全须知（重要）
--------------------

这是把电脑控制权交给外部 AI，请认真设置：

* 公网地址没有额外保护。地址泄露 + 有人能拿到令牌
  就等于开门。不用的时候请关闭隧道，或退出程序。

* OAuth 授权页需要粘贴令牌才能通过，
  所以光有地址别人也连不上。

* 「权限范围」是硬边界，AI 只能碰你列出的文件夹。
  默认是 桌面 / 文档 / 下载。

* 「允许运行命令」风险最高。不确定就关掉，
  只保留文件读写。

* 令牌可以重新生成，换掉之后所有已连接的 AI
  都要重新授权。


五、数据存放
------------

配置文件：%APPDATA%\zhiqiao\config\config.json
界面里点「关于 → 打开目录」可以直接跳过去。

卸载：删掉整个文件夹即可，不写注册表。


六、常见问题
------------

Q: 隧道一直转圈？
A: 检查网络。cloudflared 需要连 Cloudflare 的服务器，
   公司网络或某些地区可能被拦。

Q: AI 连不上 / 提示「无法识别 OAuth」？
A: 按顺序检查三件事：
   1. 程序是否在运行
   2. 状态是否显示「公网可达」
   3. 填的 URL 是否是 https://xxx.trycloudflare.com/mcp
      而不是 127.0.0.1 或 localhost

   最常见的原因就是填了本地地址，或者用了上一次的旧地址。

Q: 地址为什么每次都不一样？
A: 临时隧道地址是随机的，程序重启就变。
   程序关了再开，AI 那边要重新填新地址。

Q: 授权时提示令牌不正确？
A: 从「连接 AI」页重新复制，注意不要带多余空格。

Q: 提示「找不到 cloudflared.exe」？
A: resources 文件夹里应该有 cloudflared.exe，别删它。

Q: 能固定地址吗？
A: 临时隧道不能。要固定域名得注册 Cloudflare 账号
   建 named tunnel，那是另一套配置。
