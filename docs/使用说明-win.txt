智桥-zhiqiao 1.3.0
=======

让网页上的 AI（ChatGPT / Claude）通过 MCP 操作这台电脑。


一、怎么用
----------

1. 双击「智桥-zhiqiao.exe」
2. 首次启动会自动生成固定公网地址（约 5-15 秒）
3. 如果固定地址还在连接，界面会先显示「临时加速地址」，可以先复制它使用
4. 出现固定地址后，点「复制完整配置」
5. 到 AI 里添加 MCP 服务器

固定地址会一直保留：重启电脑、重启程序、断线重连都不会变。
只有你在「概览 → 公网地址 → 更换地址」里主动确认，地址才会换。


二、连接审批
------------

新设备第一次请求连接时，程序会停下来等你在「连接记录」里批准：

1. 进入「连接记录」→「待批准连接」
2. 看设备名称、IP 地址和客户端信息
3. 点「允许」或「拒绝」
4. 3 分钟内不处理，请求会自动过期，对方需要重新申请连接

已允许的设备会显示在下面的「设备记录」里。
同一客户端批准后，后续工具调用不会重复询问；只有更换公网地址或密钥导致记录刷新后，才需要重新批准。
每行的下拉框可以选「断开连接」；断开后对方再次请求会被挡住，需要你重新允许。


三、记忆库（AI 上下文交接）
---------------------------

AI 完成任务前可以调用 `memory_save` 把摘要、路径、决定和下一步保存到本机。
下一个 AI 通过 `memory_search` / `memory_get` 读取同一条记忆，不用从头开始。

程序默认开启「自动记录会话记忆」：每轮工具调用结束后空闲 60 秒，
会自动把这一轮的工具调用、参数摘要和结果写入记忆库，作为 AI 忘记调用
`memory_save` 时的兜底。自动记录不包含 AI 的完整聊天原文；需要完整交接
时仍应让 AI 调用 `memory_save`。

界面左侧「记忆库」可以查看、搜索、展开和删除这些记录。
记忆文件位置：%APPDATA%\zhiqiao\config\memory.json


四、两种连接方式
----------------

方式 A：客户端要求 OAuth（ChatGPT 就是这样）
------------------------------------------------
1. URL 填：https://你的固定地址/mcp
2. 身份验证选：OAuth
3. 浏览器会自动打开授权页
4. 把「连接 AI」页的访问令牌粘贴进去，点授权
5. 完成

不需要手动填 Header，也不需要 client id / secret。

方式 B：客户端支持自定义 Header（Claude 等）
--------------------------------------------
点「复制完整配置」，把 JSON 贴进去。内容是：

{
  "mcpServers": {
    "my-computer": {
      "type": "http",
      "url": "https://你的固定地址/mcp",
      "headers": { "Authorization": "Bearer 你的令牌" }
    }
  }
}

两种方式可以同时用，互不影响。


五、界面说明
------------

概览      服务状态、固定/临时公网地址、请求统计
连接记录  待批准设备、已连接设备、IP、断开/允许
记忆库    查看和搜索上一个 AI 留下的上下文
连接 AI   连接配置和访问令牌（OAuth 授权时要粘贴的那个）
权限范围  公网地址方式、允许访问的文件夹、命令和桌面工具开关
可用工具  工具包清单（文件增强、系统运维、桌面辅助、记忆）


六、固定地址说明
----------------

* 默认使用「固定地址」模式，地址由本机 SSH 密钥绑定。
  重启电脑、重启程序、掉线重连都会回到同一个地址。
* 只有点「更换地址」并确认，才会生成新密钥和新地址。
* 固定地址超过 5 秒还没连上时，程序会自动开启「临时加速地址」，
  可以先复制临时地址让客户连接，固定地址恢复后会自动切换。
* 如果界面提示「注册固定地址」，点一下按网页提示绑定免费账号。
  绑定不会改变当前地址，只是保证这个固定地址长期可用。
* 「权限范围 → 公网地址方式」里可以切换：
  - 固定地址（推荐，免费）
  - 临时地址（cloudflared，重启会变）
  - 自有 Cloudflare 域名（需要自己的域名和 Named Tunnel Token）


七、工具包
----------

文件增强：hash_file、find_files
系统运维：list_processes、kill_process、network_info、disk_usage
桌面辅助：clipboard_get、clipboard_set、screenshot
记忆：memory_save、memory_search、memory_get、memory_list、memory_delete、memory_stats

桌面工具默认开启，可在「权限范围 → 允许桌面工具」关闭。


八、安全须知（重要）
--------------------

这是把电脑控制权交给外部 AI，请认真设置：

* 公网地址没有额外保护。地址泄露 + 有人能拿到令牌
  就等于开门。不用的时候请关闭隧道，或退出程序。
* 新设备必须经过你批准，3 分钟内不处理就自动过期。
* 「权限范围」是硬边界，AI 只能碰你列出的文件夹。
* 「允许运行命令」风险最高。不确定就关掉，只保留文件读写。
* 令牌可以重新生成，换掉之后所有已连接的 AI 都要重新授权。


九、数据存放
------------

配置文件：%APPDATA%\zhiqiao\config\config.json
固定地址密钥：%APPDATA%\zhiqiao\ssh\tunnl_ed25519
连接记录：%APPDATA%\zhiqiao\config\connections.json
记忆库：%APPDATA%\zhiqiao\config\memory.json

卸载：删掉整个文件夹即可，不写注册表。


十、常见问题
------------

Q: 隧道一直转圈？
A: 检查网络。固定地址走 SSH（proxy.tunnl.gg），
   临时地址走 cloudflared（Cloudflare）。公司网络或某些地区可能被拦。

Q: AI 连不上 / 提示「无法识别 OAuth」？
A: 按顺序检查：
   1. 程序是否在运行
   2. 状态是否显示「公网可达」
   3. URL 是否是 https://你的地址/mcp，而不是 127.0.0.1

Q: 地址为什么每次都不一样？
A: 只有「临时地址」模式会这样。固定地址模式重启不会变。
   固定地址若显示「注册固定地址」，绑定免费账号后即可长期保留。

Q: 授权时提示令牌不正确？
A: 从「连接 AI」页重新复制，注意不要带多余空格。

Q: 提示「找不到 cloudflared.exe」？
A: resources 文件夹里应该有 cloudflared.exe，别删它。
   固定地址模式不依赖 cloudflared。

Q: 怎么让上一个 AI 的记忆给下一个 AI 用？
A: 让 AI 结束前调用 memory_save；下一个 AI 开始时会调用
   memory_search 读取同一批记忆，也可以在人界面「记忆库」查看。
